⚙️ Configuration Steps

1

Install the Module

Go to Apps → Search "Pincode Delivery Checker" → Install

The "Check Delivery Availability" widget automatically appears on all product pages.

2

Add Serviceable Pincodes

  • Go to Website → eCommerce → Products → Delivery Pincodes
  • Click New and enter the Pincode, City, State, Country
  • Set Delivery Days (default 5 — used to calculate the estimated delivery date)
  • Toggle COD Available and Serviceable as needed
  • Use the Import button to bulk-upload pincodes via CSV
3

Customer Checks Delivery on Product Page

  • Customer visits any product page on your website
  • Scrolls to the "Check Delivery Availability" section below Add to Cart
  • Enters their pincode and clicks Check (or presses Enter)
  • If serviceable: shows "Delivery available! Estimated delivery by <date>" and COD note
  • If not serviceable: shows a clear "not deliverable" message
4

How the Estimated Date is Calculated

Estimated delivery date = Today + Delivery Days for that pincode, skipping Sundays.

Example: Delivery Days = 5 → counts 5 working days from today (Sundays not counted) to get the estimated date.
